Database Designs
===============

OVERVIEW
--------
This folder is for this part of my course. – 'Off-Platform Project: Designing a Database From Scratch'

---

#### Why Did I Build This?
I want to practice and develop my skills in thinking about data and how it relates to each other.

#### What I Have Learned:
* I have learned about database schemas, Primary keys, Foreign keys, and the types of relationships that can be defined with them. 
Such as, one-to-one, one-to-many, and many-to-many.
* I will use my knowledge of SQL to create my database and explore concepts that exist within it.
* I will learn and develop my skills with dbdiagram.io to design my database schemas.
* I will learn and develop my skills using pgAdmin 4.
